About the program

GEOSPATIAL MODELLING FOR PUBLIC HEALTH APPLICATIONS

Run by the MAP Project team at the Ifakara Health Institute, this program brings together researchers, students, and practitioners to strengthen skills in modern statistical and spatial data analysis — with a focus on real-world public health applications.

Selected applicants join a structured onboarding path with hands-on projects, mentorship from senior researchers, and access to the tools we use in production research.

R programming Data wrangling, visualization, and reproducible workflows.
Spatial data Vector & raster analysis with sf, terra, and friends.
Bayesian statistics Modelling under uncertainty with modern tools.
Applied health data Real-world epidemiology and public-health analytics.
